## 一、总账：三个数字各自是什么（本轮最关键的口径澄清）

上一轮报告里 18 / 23 / 26 **三个 N 值并存**，本轮查明它们**各自有实际来源**：

| 数字 | 实际所指 | 计算依据 | 是否与成片时长相加 |
|---:|---|---|---|
| **18.4 s** | **21 个镜头拍表内部已含的「静默画面尾」**（旁白播完后画面仍在动的时间） | 5 个镜头的正偏离之和：2.4 `+2.7`、3.2 `+1.3`、3.6 `+7.4`、4.1 `+1.3`、5.1 `+1.8` | ❌ **不相加**——它们**已在该镜头的拍表跨度内**，而拍表跨度就是镜头时长 |
| **23.0 s** | **片级结构块**：片头标题卡 6.0 + 章节卡 ×4（各 3.0）+ 结尾收束 5.0 | 任务书 §三.4 的定义 | ✅ **相加**（是本轮的正式 N） |
| **26.0 s** | 23.0 s **再加一张 3.0 s 的章节间过渡**（第 1 章末尾那张卡被同时当成章节卡与过渡） | CA-14.6.1 §4.2 的逐章分派 | ⚠️ **加了 3.0 s 会重复计一次章节卡**；**不采用** |

> **结论：18.4 s 与 23.0 s 是「镜头内」与「片级」两个不同层级，不是两个可选项，更不能相加。**
> 上一轮报告的 583.8 / 562.3 / 542.4 用的是 26.0 s，**比正式口径多算了 3.0 s**。

### 1.1 21 镜拍表的正负偏离总账

| 类别 | 镜头数 | 合计 |
|---|---:|---:|
| **负偏离**（拍表跨度**短于**旁白，需重新配速） | 10 | **−32.9 s** |
| 在容差内（\|偏离\| < 1.0 s） | 2 | −0.9 s（2.3）/+0.4 s（4.3） |
| **正偏离**（拍表跨度**长于**旁白，即静默画面尾） | 5 | **+18.4 s** |
| **净差** | — | **−14.4 s** |

**交叉核对**：已知拍表跨度的 17 镜合计 **359.0 s**；同 17 镜的旁白 A@135 合计 **374.7 s**；
`374.7 − 359.0 = 15.7 s`。与按逐镜分别求和所得的净差 `−14.4 s` 相差 **1.3 s**，
差额来自 2.3 与 4.3 两个在容差内的镜头（`−0.9 + 0.4`）与取整。
→ **两份算法在 1.3 s 内一致，账本闭合。**

## 二、镜头 2.4：核验结果与建议

### 2.1 原始记录（逐字核对，未改动）

| 项 | 原分镜记录 | 位置 |
|---|---|---|
| 旁白 | `So the population is not spread across the country. It is stacked, very high, in a very small number of places.` | L215 |
| 词数 | **21 词** | L213 |
| **预计时长** | **9.3 s（21 词 / 135 wpm）** | **L217** |
| 拍 a | `0.0–4.0 s`（4.0 s） | L227 |
| 拍 b | `4.0–9.0 s`（5.0 s） | L228 |
| 拍 c | `9.0–12.0 s`（3.0 s） | L229 |
| 拍表跨度 | **12.0 s**（0.0 → 12.0） | L227–229 合计 |
| 末帧静止 | 「末帧 **1.5 s** 静止」——**含在拍 c 内** | L229 |
| 结束转场 | 「**交叉淡化 0.5 s** 到第 3 章」——**另计** | L231 |

**验算**：`60 × 21 ÷ 135 = 9.333 s → 9.3 s`。**L217 的 9.3 s 算术正确**，
它是「21 词在 135 wpm 下的纯旁白时长」。

### 2.2 冲突是否存在

| 项 | 值 |
|---|---|
| 分镜**宣称**的镜头时长（L217） | **9.3 s** |
| 拍表**跨度**（L227–229） | **12.0 s** |
| **差额** | **+2.7 s** |

> ✅ **确认存在 2.7 s 冲突。** 任务书 §六 所述「原标注约 9.3 秒；分拍时间可能跨 12.0 秒」**核对属实**。
> 差额来源：**L217 写的是「旁白时长」，而拍表写的是「镜头时长」，两者被当成了同一个量。**

### 2.3 该冲突的性质：不是错误，是「静默画面尾」未被说明

**反解可以证明 12.0 s 的拍表设计意图**：

| 反解 | 结果 |
|---|---|
| 要让 21 词恰好填满 12.0 s，需要语速 | **105.0 wpm** |
| 要让 21 词在 135 wpm 下填满 12.0 s，需要词数 | **27 词（+6 词）** |

**105 wpm 远低于本片预算基准（130 wpm）**，属于异常慢的语速。
**因此 12.0 s 的拍表跨度不可能被理解为「旁白要铺满 12 秒」。**

**正确的解释**：旁白（9.3 s @135 wpm）在镜头**开头连续播完**，
其后是**拍 c 的收尾动作**——三条标线向左投影到地图、依次点亮方块/两省/三省、
淡入 `Stacked, not spread.`、末帧 1.5 s 静止。**这段时间无旁白。**

**静默画面尾随语速变化**（拍表跨度固定为 12.0 s）：

| 语速 | 旁白 A | **静默画面尾** |
|---|---:|---:|
| 125 wpm | 10.08 s | **1.92 s** |
| 130 wpm | 9.69 s | **2.31 s** |
| **135 wpm** | 9.33 s | **2.67 s**（即 12.0 − 9.3） |

> 上表的「2.7 s」是 **135 wpm** 下的值。**任务书 §六 所述「可能跨 12.0 秒」核对属实**；
> 静默尾的确切长度**取决于实测语速**（见 §五 D-a）。无论取哪一档，**都必须先看旁白播完在哪一秒**。

### 2.4 2.7 s 是否够拍 c 用

| 拍 c 在 12.0 s 口径下的可用时间 | 3.0 s（9.0–12.0 s） |
|---|---|
| 拍 c 需完成的动作 | ① 三条标线同时向左投影 ② 依次点亮方块 → 两省 → 三省（**三个依次动作**） ③ 淡入 `Stacked, not spread.`（L5 52 px） ④ 末帧静止 1.5 s |
| 判定 | **3.0 s 内完成 ①②③ 后仅余约 1.5 s，与「末帧 1.5 s 静止」正好吻合 → 拍 c 的 3.0 s 是被末帧静止占满的** |

→ **因此把镜头压缩到 9.3 s 会吃掉拍 c 的全部剩余时间**，使「投影 + 三次点亮」无法完成。
**压缩方案不可行。**

### 2.5 建议（两项，均为口径标注，不是重设计）

| # | 建议 | 说明 |
|---:|---|---|
| **R2.4-a** | **把 L217 的「预计时长」由 `9.3 s` 改为 `12.0 s`**，并改为两段式标注：<br>`**预计时长**：12.0 s（旁白 9.3 s @135 wpm + 静默画面尾 2.7 s）` | **这是本轮首推**。镜头时长与拍表跨度一致，旁白量与静默量分开列明，不再混为一谈。**注：若实测语速为 125 或 130 wpm，括号内的静默尾应写 1.9 s 或 2.3 s（见 §2.3 表）** |
| **R2.4-b** | 在拍 c 的行内**明确标注**静默画面尾的起止：<br>`c 9.0–12.0 s`（其中 **旁白约 9.3 s 处结束，9.3–12.0 s 无旁白**） | 消除「旁白到底铺到哪一秒」的歧义；便于剪辑时把旁白与画面动作对齐 |

**备选（不推荐）**：

| 方案 | 内容 | 为何不推荐 |
|---|---|---|
| X1 | 保持 `9.3 s`，把三拍压缩为 9.3 s | **拍 c 只剩 0.3 s**，投影与三次点亮无法完成 |
| X2 | 把旁白从 21 词扩到 **27 词**（+6 词）填满 12.0 s | 会改动 V6 冻结文本；且 2.4 是本章结论句，**加词会削弱「stacked」这个隐喻的力度**。**属 V7 阶段的取舍，不在本轮** |
| X3 | 保持 `9.3 s`，另把 12.0 s 记为「镜头 2.4 + 2.7 s 独立时间」 | 会把已含在拍表内的时间**再加一次**，违反任务书 §三.6 |

### 2.6 对时长预算的影响

按 **R2.4-a**（镜头 2.4 = 12.0 s）：镜头 2.4 的 **2.7 s 静默画面尾已含在 12.0 s 内**，
**不进入片级 N（23.0 s）**。→ **对报告一的 N = 23.0 s 无影响。**
