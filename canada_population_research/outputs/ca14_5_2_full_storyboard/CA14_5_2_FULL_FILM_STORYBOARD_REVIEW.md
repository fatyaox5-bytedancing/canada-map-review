## 一、五章视觉形式的变化与统一

### 1.1 变化：每一章的主要视觉形式都不同

| 章 | 章节名 | 主要视觉形式 | 观众在本章学到的新「看的方式」 |
|---|---|---|---|
| 1 | *A Country That Looks Empty* | **点云 + 距离阶梯** | 尺度：这些地方彼此极远 |
| 2 | *Two Squares* | **几何框 + 缩放对比 + 满条** | 面积：集中区小到可以用方块量 |
| 3 | *One Corridor, Two Different Things* | **一维剖面 + 柱状分布 + 采样条** | 间距：沿线有的地方够得到中心，有的够不到 |
| 4 | *The Other Half* | **跨尺度连续运动 + 最近邻连线 + 二分版面** | 反例：另一半国土上连「最近的邻居」都在几百公里外 |
| 5 | *What This Map Does and Doesn't Say* | **并置满条 + 距离色带 + 减法收束** | 边界：我们知道什么、不知道什么 |

**结论：五章的视觉形式有实质区分，未形成模板。**

逐项核对用户提出的「避免全片反复使用同一种『地图加圆点加标题』」：

| 章 | 是否只用了「地图 + 圆点 + 标题」 | 判断 |
|---|---|---|
| 1 | 是（1.1/1.2/1.4 都是） | 第 1 章**部分符合该描述**，但 1.2 的距离阶梯与 1.3 的双尺度条已经打破它 |
| 2 | 否 | 2.1 的核心是**几何框与缩放**，2.3/2.4 的核心是**满条与堆叠柱**（非地图） |
| 3 | 否 | 3.2/3.3/3.4/3.5 全部是**一维图形**（轴、柱、采样条），地图仅作压暗背景 |
| 4 | 否 | 4.3 是**二分版面**，完全不含地图 |
| 5 | 否 | 5.2 是**距离色带**，5.4 是**减法收束**，均非「圆点 + 标题」 |

**唯一需要盯住的重复风险**：**1.1 拍 b（逐点显现）与 2.4 拍 a（逐点堆叠）都操作 1,026 个点**。两者动作不同（铺开 vs 堆起），**但若点的基础配色与半径不一致，会被看成两套数据**。**处置：两处必须共用同一份点样式定义。**

## 二、主要风险（按严重度排序）

### R1｜第 3 章的底图色阶与全片冲突（严重度：高，但可控）

**事实**：`outputs/ca03b3a_maps/CA03B_3A_01_SOUTHERN_ONTARIO_ST_LAWRENCE.png`（1920×1080，0.870 km/px）是 **CA-03B-2E 的暖橙五级色阶**（`ca03a/_ca03b3a_map.json` 的 `palette` 字段明确记录）。而第 1、2、4、5 章使用的 `CA06_01_ORIGINAL_CANADA_2D.png` 是**冷蓝五档**。

**风险**：第 2 章末与第 3 章之间、第 3 章与第 4 章之间都有交叉淡化。**在淡化中点会同时出现两套色阶**，违反 CA-08 §5.4，且会让观众以为「橙色区域 = 有问题的区域」。

**处置**：**必须重出一版冷蓝的区域底图**（同一范围、同一投影参数、同一 km/px）。**这是全片最高优先级的素材制作项**，因为它阻塞第 3 章全部 6 个镜头。投影参数已存在：`ca03a/_ca03b3a_map.json`（Albers PHI1=44 / PHI2=66 / LAM0=−105 / PHI0=50；`bounds_lonlat` = [−81.6, 42.3, −70.4, 47.05]）。

### R2｜第 2 章的方块边界无法复现（严重度：高）

**事实**：`CA04A_SPATIAL_STATISTICS.csv` 第 138/140 行给出两个 200 km 单元的中心坐标、中心数与人口（Toronto = `(-79.5, 44.1)` / 89 个 / 8,493,412；Montréal = `(-74.4, 45.9)` / 96 个 / 4,573,552），口径文字为「原点 lon−96/lat45，x 含 cos45 订正」。

**本次穷举 2,520 种参数组合（经度步长 6 种 × 纬度步长 5 种 × 原点 7×6 × floor/round 两种）尝试复现这两个计数，全部失败。**同时确认了另一件事：该网格在真实纬度上的面积（lat 44.1 → 203.1×200.0 km；lat 45.9 → 196.8×200.0 km）**合计 79,990 km²**，**与旁白的 `about eighty thousand square kilometres` 吻合**——所以旁白的面积是对的，**但对不上的是「哪一块地」**。

**风险**：若渲染时随手画一个 200×200 km 的方块，**方块边界很可能与计数边界错开**，于是「画面上写了 89 个中心的那个方块」**并不包含那 89 个中心**。这是事实性错误。

**处置**：见分镜文件 §六 待裁定 1。**建议 A**：回溯 CA-04A 的网格生成脚本取得精确规则，**并用同一规则复现 89 / 96 两个计数后才允许渲染**。

### R3｜1,026 个人口中心的多边形边界是否存在（严重度：高）

**事实**：本项目确认存在的是**形心点**（`ca04/_ca04a_centres.csv`，1026 行，含 `lat` / `lon` / `pop2021` / `nn_km`）。**本次未发现任何人口中心的多边形几何文件。**

**风险**：以下镜头**依赖多边形边界而非形心点**：

| 镜头 | 依赖方式 |
|---|---|
| 1.1 拍 b | 逐点显现（**形心点即可**，不依赖多边形） |
| 1.4 拍 b | 底图淡出后叠加六标记（形心点即可） |
| **5.3 拍 b** | **「1,026 个多边形边界全部描出」——必须有多边形** |

**处置**：若多边形不存在，5.3 拍 b 退路为**「以形心为中心画固定半径的圆，并明确声明这是示意」**——**但那样「边界」这个词就不能用**，旁白的 `People live outside these boundaries too` 会失去画面支撑。**建议优先确认多边形几何是否存在**（见 §三 缺口 G1）。

### R5｜第 3 章 3.3 的分箱边界敏感性（严重度：中高）

### R6｜「五个方向无数据」的画面可能被读成「有这些数据」（严重度：中）

**事实**：本项目**不存在**气候、地形高程、永久冻土、土壤、水系、历史人口序列（仅部分）、经济/产业数据层。

**风险**：4.3 拍 b 要画出「五个方向」的轮廓并叠「无数据」标记。**若这五个轮廓画得有地理特征**（真实海岸线、真实等高线），观众会以为本片有这些数据、只是没展示。

**处置**：分镜已规定五个轮廓必须是**抽象线条示意**（无地理形状、无坐标、无数据），**且每个都叠「无数据」斜线**，**五个同等对待（同大小、同线宽），不得突出或淡化任何一个**——因为**本片没有做任何排除性检验**，不能说「不是气候造成的」。

### R8｜59% 的分母与「人为定义的框」（严重度：中）

**事实**：旁白的原话是 `Inside the map we drew for that corridor`——**旁白自己承认这是人为定义的框**。并且 414 与 424 是**两套判定方式**（3A 投影像素形心 + 0.02° 容差 → 414；形心经纬直判 → 424），**本片只用 414**。

**本次已把差异量化归因**：用 1,026 个形心做经纬直判**精确复现 424 个 / 17,859,490**；边界向内收紧 0.10° 后得到 **413 个 / 17,824,791**，与 3A 的 414 / 17,829,125 **只差 1 个中心**。**差异来自边界附近约 10 个中心对投影/容差的敏感，不是数据矛盾。**

**处置**：分镜 3.1 已规定走廊框必须**画出边界**（不得画成有官方依据的边界），**且 0 处出现 424**、**0 处出现 58.77%**。

### R9｜全片 21 镜中有 14 镜依赖同一张全国底图（严重度：中）

**事实**：1.1 / 1.2 / 1.3b / 1.4 / 2.1 / 2.2 / 2.3 / 2.4 / 4.1 / 4.3 / 5.1 / 5.2 / 5.3 / 5.4 共 **14 镜**都用 `CA06_01_ORIGINAL_CANADA_2D.png`（其余 7 镜用区域底图或纯版面）。

**风险**：**这张图尚未经过 CA-08 §G8 的人工视觉验收。**CA-08 §G8 明确规定**三张关键地图需人工视觉验收，是硬性门槛**。**若该图在第 2 章渲染后被判定不合格，第 1、2、4、5 章都要重做。**

**本次未能核对的一件事**：该图**是否已带有城市名称标注**。CA-12 的名称标注是在**区域图**上做的。**若全国图没有名称，六个中心的名字需要另画**——而 Toronto / Montréal / Ottawa–Gatineau 三者相距仅约 400 km，**在 2.906 km/px 下仅约 137 px，标名是本片最可能的可读性问题**。

**处置**：① **在第 2 章渲染前完成 CA-08 §G8 的人工视觉验收**（这是硬门槛）；② 把「全国底图是否含名称标注」列为一个**像素检测任务**（在已知地名位置采样底图像素并与周边比较），**不靠目视判断**。

### R10｜时长为词数换算值，全片未与配音对齐（严重度：中）

**事实**：本项目 TTS 通道被沙箱阻断（CA-13.4 已穷尽 6 条路径，SAPI 返回 `E_ACCESSDENIED`），**没有任何一段旁白被实际朗读或合成过**。全部时长（全片 414 s）都是 **135 wpm 的词数换算值**。

**风险**：实际语速可能在 120–150 wpm 之间，**全片实际时长可能在 385.6–482.0 s 之间浮动（±12%）**。而本稿的分镜是为 135 wpm 设计的，**若实际语速差 10%，全部「拍」的时间轴都要重排**。


**本稿的精确值**：全片 **964 个可朗读词** / **135 wpm** = **428.4 s**；120 wpm = 482.0 s；150 wpm = 385.6 s。（V6 共有 5 个破折号 `—`：1.2 / 3.1 / 4.1 各 1 个、5.2 有 2 个；它们不计入朗读词数，故空白 token 总数为 969。）

**处置**：分镜中的每一拍都给出了**内容顺序**而非硬性秒数依赖，**重新对齐时应按内容顺序重排，而不是按秒数裁剪**。**配音必须优先产出**（它阻塞一切时间轴工作）。

### R11｜旁白 1.3 的「超过三千公里」余量很薄（严重度：低，但需知情）

**事实（第 1 章，本次复核）**：六个中心 15 对距离降序前三：Montréal–Vancouver **3,663.43**、Toronto–Vancouver **3,331.98**、Montréal–Calgary **3,010.68**。

**风险**：旁白 1.3 说 `The farthest are more than three thousand kilometres apart`。**这句严格成立于 3 对，而第 3 对（3,010.68）只比 3,000 多 10.68 km（0.36%）。****若任何一环（坐标、投影、四舍五入）有微小变化，这句话就会变成只成立于 2 对。**

**处置**：**第 1 章的 1.3 已经设计为「>3,000 km」而非精确值**（与旁白一致），**这是正确的选择**。本报告仅记录该事实供人工知情，**不建议修改已冻结的旁白**。

## 四、关键视觉决策（本稿的核心设计选择）

| # | 决策 | 替代方案 | 为什么选它 |
|---:|---|---|---|
| D1 | **2.1 用「镜头拉到全国」做尺度论证** | 静态图 + 说明文字 | **观众在拉远过程中亲眼看着两个方块变小**——这个体验无法用文字替代。这是全片唯一的「运动即论证」 |
| D2 | **2.4 把 1,026 个点真的「堆起来」** | 画一根抽象柱状图 | 旁白的词是 `stacked`。抽象柱只表达「多」，**搬点堆叠才表达「堆」** |
| D3 | **3.2 把斜向走廊「取直」成一维轴** | 在真实地图上比较疏密 | 斜线上的间距在屏幕上呈现不同长度，**眼睛无法比较**；取直后「哪里稀」成为直观判断 |
| D4 | **3.4 / 3.5 把 71 / 32 / 47 个采样点真的画出来，并画「到最近中心的连线」** | 只画线段 + 一个百分比 | **决定一个点是否超阈值的是它到最近中心的距离**。画出这条距离，「超出 25 km」才是可见的几何事实 |
| D5 | **3.5 用 3.4 完全相同的采样视觉** | 换一种图形语言 | **对照的有效性建立在两个镜头不可区分上** |
| D6 | **3.6 用「中央留白」代表未解释** | 用问号 / 感叹号等装饰 | **空白本身就是「解释空缺」**。装饰会把诚实的不确定性渲染成悬念营销 |
| D7 | **4.1 用「上升 + 北移」的连续运动，而不是切换镜头** | 硬切到北部 | 本章主题是「另一半」。连续运动使「北」是同一个国家的另一边 |
| D8 | **4.1 的两套口径做成两块绝不合并的卡，并标 `≠`** | 写「12–14 个中心」 | **那会抹掉本镜的全部意义**（旁白用整句说这是两种定义） |
| D9 | **4.2 用「与走廊同屏对比」给北部尺度参照** | 只画三条距离线 | **没有参照，550 km 在北部地图上只是一条线** |
| D10 | **5.2 用「距离色带」而非 561 条连线** | 画蛛网 | **561 条线在任何屏幕上都是噪声**；色带把「561 个值」变成可看的分布，**并让「中位数在正中」成为位置事实** |
| D11 | **5.3 数字 `30,389,999` 独占版面中心、全片最大字号** | 与其他数字同等 | 旁白**逐位念出**这个数字（异常强调），画面必须给出对等分量 |
| D12 | **5.4 用「减法」收片（撤掉四章加的全部强调，回到开场构图）** | 加一张总结图 | **收片再加一层就是数据 PPT**。减法表达「我们知道的和开场时一样多，只是知道了边界在哪」 |
